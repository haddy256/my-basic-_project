👋 My Profile Page

A simple personal profile page built with HTML and CSS. This is a small beginner project I made to practice web basics and Git/GitHub.

📖 About

This page introduces who I am, what I study, and what I'm interested in. It's my first step toward building a personal portfolio website.

✨ Features
Profile photo and short introduction
Education and skills section
Links to my GitHub and contact info
Simple, clean design that works on phone and desktop

🛠️ Built With
HTML
CSS
Git & GitHub

my-basic-_project/

🚀 How to Run
Clone the repository
bash
   git clone git@github.com:haddy256/my-basic-_project.git
   cd my-basic-_project
Open index.html in your web browser (just double-click it).
